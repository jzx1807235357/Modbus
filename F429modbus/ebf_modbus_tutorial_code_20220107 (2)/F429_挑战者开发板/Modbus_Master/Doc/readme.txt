【*】程序简介

-工程名称：FreeModbus-Master例程
-实验平台: 野火STM32 F429 开发板 
-MDK版本：5.23
-ST固件库版本：1.24.0


【 ！】功能简介：
通过FreeModbus协议栈进行通信，可以用Modbus上位机连接开发板进行调试。
通过modbus_master_test.h中的宏定义选择具体功能。

学习目的：通过阅读Modbus官方文档结合历程学习FreeModbus通信原理。

【 ！！】注意事项：
本工程已按硬件打开 MODBUS_MASTER_USE_CONTROL_PIN，通过 PD11 控制 485 收发方向。
RE 与 DE 短接后接 PD11：高电平发送，低电平接收。

/*********************************************************************************************/

【*】 引脚分配
    PD5     ------> USART2_TX
    PD6     ------> USART2_RX
    PD11    ------> 485 RE/DE（方向控制）
	
/*********************************************************************************************/

【*】 时钟

A.晶振：
-外部高速晶振：25MHz
-RTC晶振：32.768KHz

B.各总线运行时钟：
-系统时钟 = SYCCLK = AHB1 = 180MHz
-APB2 = 90MHz 
-APB1 = 45MHz

C.浮点运算单元：
  不使用
